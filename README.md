# Beumer Case Presentation

This repository contains a presentation created with [Marp](https://marp.app/).

## Prerequisites

Install Marp CLI globally:

```bash
npm install -g @marp-team/marp-cli
```

## Generate Presentation

To generate the HTML presentation from `case.md`:

```bash
marp case.md -o presentation.html
```

## Generate PDF

To generate a PDF version instead:

```bash
marp case.md -o presentation.pdf
```

## View Presentation

Open the generated `presentation.html` in your browser to view the presentation.

## Edit Slides

Edit `case.md` to add or modify slide content. Each slide is separated by `---`.
